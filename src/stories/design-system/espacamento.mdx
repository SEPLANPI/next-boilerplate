# Espaçamento

O sistema de espaçamento é projetado para manter consistência visual em toda a aplicação. Ele é construído em duas camadas:

1. **Escala Base**: Uma sequência progressiva de valores numéricos
2. **Tokens Semânticos**: Abstrações com nomes significativos para uso em contextos específicos

Todos os valores são calculados usando a variável `--mantine-scale`.

## Escala Base de Espaçamento

A escala base segue uma progressão que começa com valores pequenos e precisos (px, 0.5) para ajustes finos,
avançando para incrementos maiores conforme os valores aumentam. Isso permite:

- Ajustes precisos em componentes pequenos (0.5 - 4)
- Espaçamentos médios para layouts comuns (5 - 16)
- Grandes espaços para seções maiores (20 - 96)

## Tokens Semânticos do Mantine

Os tokens semânticos do Mantine fornecem uma camada de abstração que mapeia para valores específicos da escala base.
Eles são projetados para uso em componentes e padrões comuns do Mantine.

Estes tokens são especialmente úteis ao trabalhar com componentes do Mantine que aceitam a prop `spacing`, como:

- `Stack`
- `Group`
- `Grid`
- `Table`
- Propriedades de padding em modais e cards

### Uso com Componentes Mantine

```tsx
// Exemplo de uso dos tokens semânticos
import { Stack, Group } from '@mantine/core'

// Espaçamento vertical usando token md (16px)
<Stack spacing="md">
  <div>Item 1</div>
  <div>Item 2</div>
</Stack>

// Espaçamento horizontal usando token sm (12px)
<Group spacing="sm">
  <Button>Ação 1</Button>
  <Button>Ação 2</Button>
</Group>
```

## Exemplos

### Componentes Mantine

Os tokens de espaçamento podem ser aplicados em diversos componentes do Mantine:

```tsx
import { Stack, Group, Grid } from '@mantine/core'

// Espaçamento vertical (Stack)
<Stack spacing="xs">Espaçamento compacto</Stack>
<Stack spacing="sm">Espaçamento pequeno</Stack>
<Stack spacing="md">Espaçamento médio</Stack>
<Stack spacing="lg">Espaçamento grande</Stack>

// Espaçamento horizontal (Group)
<Group spacing="xs">Itens próximos</Group>
<Group spacing="sm">Itens com espaço pequeno</Group>
<Group spacing="md">Itens com espaço médio</Group>
<Group spacing="lg">Itens com espaço grande</Group>

// Grid
<Grid gutter="sm">Grade com espaço pequeno</Grid>
<Grid gutter="md">Grade com espaço médio</Grid>

// Padding em componentes
<Card p="sm">Card com padding pequeno</Card>
<Paper p="md">Paper com padding médio</Paper>
<Modal p="lg">Modal com padding grande</Modal>
```

### Classes Tailwind

O sistema também pode ser utilizado através das classes do Tailwind:

```tsx
// Margin
<div className="m-2">Margin em todos os lados</div>
<div className="mx-4">Margin horizontal</div>
<div className="my-4">Margin vertical</div>
<div className="mt-4">Margin top</div>
<div className="mb-4">Margin bottom</div>

// Padding
<div className="p-2">Padding em todos os lados</div>
<div className="px-4">Padding horizontal</div>
<div className="py-4">Padding vertical</div>
<div className="pt-4">Padding top</div>
<div className="pb-4">Padding bottom</div>

// Gap
<div className="flex gap-4">Espaço entre flex items</div>
<div className="grid gap-4">Espaço entre grid items</div>

// Espaçamento responsivo
<div className="p-2 sm:p-4 md:p-6 lg:p-8">
  Padding que aumenta com breakpoints
</div>

// Combinando espaçamentos
<div className="p-4 mt-6">
  Padding interno e margin superior
</div>
```

### Casos de Uso Comuns

1. **Espaçamento Básico (1-4)**
   - Espaço entre ícones e texto
   - Padding interno em botões
   - Margin entre elementos inline

2. **Espaçamento Médio (5-8)**
   - Espaço entre componentes relacionados
   - Padding em cards e containers
   - Gap em grids e flexbox

3. **Espaçamento Grande (10-16)**
   - Separação entre seções
   - Margens verticais em títulos
   - Espaço ao redor de elementos destacados

4. **Espaçamento Extra (20-24)**
   - Grandes divisões de layout
   - Espaço entre blocos de conteúdo
   - Margens para elementos isolados

### Boas Práticas

1. **Consistência**
   - Use os mesmos valores para elementos similares
   - Mantenha um ritmo vertical consistente

2. **Hierarquia**
   - Use espaçamentos maiores para separar seções diferentes
   - Use espaçamentos menores para elementos relacionados

3. **Responsividade**
   - Ajuste o espaçamento para diferentes breakpoints
   - Mantenha proporções consistentes ao escalar
