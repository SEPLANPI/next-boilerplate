# Arredondamento

O sistema de arredondamento (border-radius) fornece uma escala consistente para suavizar cantos de elementos. Os valores são calculados usando a variável `--mantine-scale`.

## Exemplos

### Componentes Mantine

Os tokens de arredondamento podem ser aplicados em diversos componentes do Mantine através da prop `radius`:

```tsx
import { Button, Card, Paper, Avatar, Badge } from '@mantine/core'

// Componentes básicos
<Button radius="sm">Botão</Button>
<Card radius="md">Card com cantos arredondados</Card>
<Paper radius="lg">Paper com cantos suaves</Paper>

// Componentes de mídia e dados
<Avatar radius="full" src="/avatar.jpg" alt="Foto do usuário" />
<Image radius="lg" src="/imagem.jpg" alt="Imagem com cantos arredondados" />

// Elementos de interface
<Badge radius="xl">Status</Badge>
<Alert radius="md">Alerta com cantos suaves</Alert>

// Inputs e campos de formulário
<TextInput radius="sm" placeholder="Campo de texto" />
<Select radius="md" data={['Opção 1', 'Opção 2']} />
```

### Classes Tailwind

O sistema também pode ser utilizado através das classes do Tailwind:

```tsx
// Arredondamento básico
<div className="rounded-sm">Arredondamento pequeno</div>
<div className="rounded">Arredondamento padrão</div>
<div className="rounded-lg">Arredondamento grande</div>

// Arredondamento em lados específicos
<div className="rounded-t-lg">Apenas topo</div>
<div className="rounded-r-lg">Apenas direita</div>
<div className="rounded-b-lg">Apenas base</div>
<div className="rounded-l-lg">Apenas esquerda</div>

// Cantos específicos
<div className="rounded-tl-lg">Topo esquerdo</div>
<div className="rounded-tr-lg">Topo direito</div>
<div className="rounded-br-lg">Base direita</div>
<div className="rounded-bl-lg">Base esquerda</div>

// Casos comuns
<div className="rounded-full">Círculo perfeito</div>
<button className="rounded hover:rounded-lg">
  Botão com transição de arredondamento
</button>
```

### Casos de Uso Comuns

- **xs - sm**: Elementos pequenos, inputs, botões secundários
- **rounded - md**: Cartões, botões primários, campos de formulário
- **lg - xl**: Modais, popovers, elementos destacados
- **2xl - 3xl**: Elementos especiais, banners
- **full**: Avatares, badges, pills
